# UI/UX Guidelines

- Prioritize fast, clear daily workflows for a real shop counter.
- Keep POS actions keyboard-friendly and reduce unnecessary steps.
- Use readable typography, accessible contrast and clear form errors.
- Use consistent currency and number formatting.
- Support responsive layouts for desktop and tablet; confirm mobile needs.
- Keep financial totals, paid amounts and due amounts visually distinct.
- Plan for Bangla and English labels; confirm language preference.
- Print styles must be tested against the selected paper size and thermal printer.
- Do not display fake dashboard metrics as real business data.
