# Inventory Costing (proposed)

Weighted Average Costing is the proposed default, pending accountant approval.

Illustrative example only:

- Existing stock: 10 units at BDT 100 each = BDT 1,000.
- New purchase: 10 units at BDT 120 each = BDT 1,200.
- Combined stock: 20 units with total cost BDT 2,200.
- Weighted average cost: BDT 2,200 / 20 = BDT 110 per unit.
- If 4 units are sold, illustrative COGS = 4 × BDT 110 = BDT 440.

Real rules must define returns, purchase expenses, discounts, damage, stock adjustments, rounding, and whether the average is recalculated per transaction. Have an accountant review before implementation.
