# Project Scope

## Foundation scope

- Next.js App Router starter.
- Strict TypeScript, Tailwind CSS, linting and formatting.
- Test configuration with meaningful starter tests.
- Prisma/PostgreSQL configuration without ERP business schema.
- Environment variable example and safe documentation.
- Project architecture and phased roadmap.

## Planned ERP scope

Products, inventory, suppliers, purchases, customers, sales/POS, payments/dues, returns/refunds, accounting, reports, user permissions, auditability, backup/recovery.

## Deferred pending approval

Public e-commerce, multiple branches/warehouses, barcode/expiry/serial tracking, external payment gateway, SMS/email notifications and data migration.

## Not promised by this foundation

- Completed ERP functionality.
- Tax/accounting compliance certification.
- Working payment-provider integrations.
- Production deployment or production database migration.
