# Module Overview

| Module                  | Planned phase | Main responsibility                        |
| ----------------------- | ------------: | ------------------------------------------ |
| Foundation              |            01 | App shell, tooling, conventions            |
| Database                |            02 | Reviewed schema and migrations             |
| Auth/RBAC               |            03 | Authentication and server-side permissions |
| Products/Inventory      |            04 | Catalogue, stock ledger, stock costing     |
| Suppliers/Purchases     |            05 | Supplier records, purchasing, payables     |
| Customers               |            06 | Customer profile and history               |
| Sales/POS               |            07 | Sales, invoice, stock deduction            |
| Payments/Dues           |            08 | Receipts, allocations, receivables         |
| Returns/Refunds         |            09 | Traceable reversals and returns            |
| Accounting/Finance      |            10 | Expenses, cash/bank and accounting         |
| Dashboard/Reports       |            11 | Operational and financial reports          |
| Public Website          |            12 | Optional online store                      |
| Security/Reliability    |            13 | Hardening, audit, backups                  |
| Production Verification |            14 | Release and recovery checks                |
