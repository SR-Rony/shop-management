# Phase 00 — Reconnaissance

## Objective

Inspect the actual repository and runtime before modifying files.

## Scope

- Inspect directory, Git status/history, package manifests and installed tool versions.
- Identify existing user changes and risks.
- Verify framework/ORM/auth compatibility from official documentation.
- Propose exact files to create or modify.

## Out of scope

- Any file edits, installs, migrations, generators, formatters or commits.

## Acceptance

- Evidence-based report; all unknowns stated.
- Exact change plan and dependencies proposed.
- Stop and wait for owner approval.
