# OpenCode Prompt — Phase 00 Reconnaissance

Read `AGENTS.md`, `README.md`, the project overview, architecture and data integrity rules first.

This task is READ-ONLY:

1. Inspect actual working directory, hidden files, Git status/branch/recent commits, manifests, configs, docs and tool versions.
2. Never read `.env` values. Report only file names and environment key names.
3. Do not create/modify/delete files, install packages, run generators/migrations/formatters, or commit.
4. Compare actual repository state with `docs/status/IMPLEMENTATION_STATUS.md`.
5. Propose an exact file-by-file plan and list blockers, risks, assumptions and commands needed for verification.
6. End with `Awaiting approval` and stop.
