# Phase 01 — Foundation

## Objective

Create the application shell, code quality tooling, tests and core documentation only.

## Scope

- Next.js App Router, strict TypeScript, Tailwind.
- Lint, format, typecheck, unit-test and E2E-test configuration.
- Safe environment example.
- Prisma configuration only; no ERP business models or migrations.
- Foundation documentation and agent instructions.

## Out of scope

- Authentication, ERP modules, real financial operations, production deployment and database migrations.

## Acceptance

- Install and all relevant checks pass locally.
- No secrets committed.
- No unreviewed destructive operations.
- Status docs distinguish verified work from unverified work.
