# Phase 12 — Optional Public Website (planned)

## Objective

Add public product browsing and online ordering only if explicitly approved.

## Prerequisites

Core ERP stable; owner confirms fulfilment, delivery, pricing, stock reservation and customer-data rules.

## Scope

Public catalogue, cart/order flow and approved integrations. Keep public APIs separate from privileged admin operations.

## Acceptance

Public users cannot access private ERP data; order and inventory reservation rules are tested; payment provider work is separately scoped.
